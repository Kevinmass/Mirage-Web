Los botones tienen que reaccionar a la interaccion con el usuario y deben distinguirse lo suficiente para que el usuario entienda que estos son funcionales e interaccionables.

Algunos componentes de reactbits que se pueden usar son:

https://reactbits.dev/components/specular-button (for glares and hovers)

https://reactbits.dev/components/fluid-glass (for glass texture)

https://reactbits.dev/components/tilted-card (buttons tilting)

https://reactbits.dev/components/glass-surface (tinted glass efect, only for static buttons that follow the page movement)

https://reactbits.dev/components/folder (for buttons that open inner sections)

https://reactbits.dev/components/spotlight-card

https://reactbits.dev/components/border-glow

https://reactbits.dev/animations/magnet

https://reactbits.dev/animations/click-spark

https://reactbits.dev/animations/shape-blur

https://reactbits.dev/animations/star-border
